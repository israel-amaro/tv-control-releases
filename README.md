# TV Control — instaladores e atualizações

Central de TVs para Windows com ADB, instalação de APKs, controle remoto e gerenciamento de aplicativos.

## Baixar

Abra [a versão mais recente](https://github.com/israel-amaro/tv-control-releases/releases/latest) e baixe o instalador `.exe` para Windows 10/11 x64. Ele já inclui as dependências necessárias.

## Atualizar sem compartilhar outro instalador

A partir da versão 1.4.0, abra **Atualizações → Buscar atualizações** no programa. Quando houver uma versão nova, clique em **Baixar e atualizar**. O aplicativo verifica o download, reinstala e reinicia preservando os cadastros e a senha.

Versões anteriores precisam receber a instalação inicial da 1.4.0 uma vez. O botão atualiza o programa Windows; não atualiza os APKs instalados nas TVs.

Este repositório é o canal público de distribuição. Ele contém instaladores e manifestos de atualização, sem tokens, chaves ADB ou dados de TVs. O código-fonte e os instaladores históricos ficam em um repositório privado do mantenedor.
